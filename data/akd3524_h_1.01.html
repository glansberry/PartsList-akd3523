BODY SERVICE PARTS LIST AKD 3524

How To Use This Parts List

Quick Start

This will get you going with the bare essentials. If you read nothing else, READ THIS QUICK START SECTION!

The Menu Frame

The Menu Frame is located on the left side of the interface, and is the main navigation system through the Parts List.
Moving the mouse over a Section heading will turn that heading red, with an underline, indicating that it is a link.
  • Clicking on a heading will expand the menu, revealing one or more sub-headings. Clicking on a heading or sub-heading will load data into the Parts List and/or the Illustration Frames.
  • When a heading is open, there will be a '(-)' symbol beside the heading; clicking on this symbol will collapse the menu, taking you back to the initial main menu.

The Parts List Frame

The Parts List Frame is located in the upper-right half of the main window, and normally displays the listing of all parts information associated with the current sub-heading and Illustration image.

The Illustration Frame

The Illustration Frame is located in the lower-right half of the main window, and normally displays the illustration image associated with the current sub-heading and parts listing.
Clicking on the Illustration image will have the following results:
  • Left Mouse Click: Clicking on the Illustration image with the left mouse button will zoom in on the image.
  • SHIFT Key Plus Left Mouse Click: While holding down the SHIFT key, clicking on the Illustration image with the left mouse button will zoom out from the image.
  • In both cases above, the point on which you clicked should never leave the Illustration Frame, re-centring itself as much as possible.
  • CTRL Key Plus Left Mouse Click: While holding down the CTRL key, clicking on the Illustration image with the left mouse button will centre the image on the point you just clicked (as much as possible), without zooming in or out. Good for navigating around a zoomed image.
    Note: On Apple Macs, use the Command Key (also called the Apple Key) instead of the CTRL Key.

The Control Frame

The Control Frame is located at the bottom-right of the main window, and adds some functionality to the interface.
  • MENU | PARTS | ILLUS: Clicking on these words will change the Menu, Parts List or Illustration Frames sizes, respectively, to give more screen real estate to other Frames.
  • RESET ILLUSTRATION: Clicking on these words will re-size the current illustration in the Illustration Frame to its initial value.
  • SEARCH: Clicking on this word will replace the menu system in the Menu Frame with the Search Frame.
  • PRINT: Clicking on this word will resize the Menu Frame, revealing the Print Frame below.
  • CONFIG: Clicking on this word will bring you to the Configuration section.
  • HELP: Clicking on this word will bring you to this Help section.

Initial Setup

Once your browser has loaded the Parts List, you may find that the frames, images and fonts are all the wrong sizes. This section will explain what to do about it.

Frame Sizes

Each frame in the Parts List is re-sizable, although in different ways. You can adjust the height of the Parts List, Illustration and Control Frames simply by clicking and dragging a border to the desired position. The width of the Menu Frame and the height of the Print Frame are adjusted in the Configuration section of the Parts List, accessed by clicking on the word 'CONFIG' in the Control Frame. Follow the instructions in Configuring the Parts List to adjust these frames.

Image Sizes

All the images in the Parts List are re-sizable. If the initial image sizes are too large or too small, you can change this behaviour in the Configuration section of the Parts List, accessed by clicking on the word 'CONFIG' in the Control Frame. Follow the instructions in Configuring the Parts List>Settings Section to adjust this initial size.

Font Sizes

The size of the fonts for the entire Parts List can only be changed with a command from the browser. Each browser handles on-the-fly resizing of fonts differently. Check the documentation for your particular browser on the procedure to change the on-screen font size.
  Mozilla, Netscape 6.x, 7.x:
  1. To increase or decrease the fonts, while holding the CTRL key, press the '=' or '-' key, respectively, or
  2. To increase or decrease the fonts, while holding the CTRL key, press the '+' or '-' key, respectively, or
  3. Choose View/Text Zoom from the menu, and choose one of: 'Smaller', 'Larger', '50%', '75%', '90%', '100% (Original Size) CTRL+0', '120%', '150%', '200%', or 'Other (300%)'.
  Internet Explorer: Choose View/Text Size from the menu, and choose one of 'Largest', 'Larger', 'Medium', 'Smaller' or 'Smallest'.

Saving the Configuration

Once you have set the frames, image and font sizes the way you want, click on the word "CONFIG" in the Control Frame at the bottom of the main window and the Configuration section will be loaded. Follow the instructions in Configuring the Parts List to save your configuration. Note: Saving the configuration will not save the font size you have set, sorry.
For more configuration options, see 'Configuration' in the Help section.

Parts List Configuration

The Parts List Configuration page allows you to change various settings, including frame sizes, and save those settings to be loaded the next time you use the Parts List.

Overview

  • To enter Parts List Configuration, simply click on the word 'CONFIG' in the Control Frame at the bottom of the Parts List Window. The menu system will automatically set itself to the proper entry, the Parts List Configuration will be loaded into the Parts List Frame and the Help file will be loaded into the Illustration Frame.
  • The 'Settings' section allows you to set various settings and optionally save those settings to be loaded the next time you use the Parts List..

Settings Section

Save Configuration On Exit?:
If this option is set to 'Yes', when you leave the Parts List by visiting another Web site, or by shutting down your browser, all of the current Parts List settings will be saved automatically.
If this option is set to 'No', the current configuration settings are not saved; when you re-load the Parts List, it will load the settings last saved, or if the settings have never been saved, the default values.
Default: 'Yes'
Configuration Saved confirmation dialog?
If this option is set to 'Yes', when the configuration is saved, either by clicking on the 'Save Configuration' button or when the 'Save Configuration Option On Exit' option is set to 'Yes', a confirmation dialog opens with the message 'Parts List Configuration Saved'.
If this option is set to 'No', no confirmation dialog box will open, although settings are still saved.
Default: 'Yes'
Sizing of images on load
This option controls the initial on-screen size of the images in the Parts List, expressed as a percentage. If you find that the images in the Parts list are too large, reduce this value. If the images in the Parts list are too small, you can increase this value. When 'Reset Illustration' in the Control Frame is clicked, images will return to this size.
Note: This option is different from the 'Image height' value in the Print Frame (see Printing>Print Options for more details) and is different from the zooming functions built-in to the Illustration Frame (see 'The Illustration Frame' for details).
Default: 100%
Width of Menu Frame:
This option specifies the width of the Menu Frame, and is expressed as a percentage of the width of the browser window. By clicking on the 'Apply' button, the value entered in the textbox is immediately applied (but not saved), and the width of the Menu Frame is adjusted.
Note: If the Menu Frame is hidden when you click the 'Apply' button, the Menu Frame will be shown (un-hidden) and adjusted to its new width.
Default: 25%
Height of Print Frame:
This option specifies the height of the Print Frame, and is expressed as a percentage of the height of the browser window. By clicking on the 'Apply' button, the value entered in the textbox is immediately applied (but not saved), and the height of the Print Frame is adjusted.
Note: If the Print Frame is hidden when you click the 'Apply' button, the Print Frame will be shown (un-hidden) and adjusted to its new height. If both the Print and Menu frames are hidden when you click the 'Apply' button, both the Print and Menu frames will be shown (un-hidden) and adjusted to the values in the 'Width of Menu Frame' and 'Height of Print Frame' textboxes.
Default: 30%
Save Configuration
Clicking on the 'Save Configuration' button will save the values entered in the 'Settings' section.
These values are stored in a cookie in your computer's browser. If you have cookies disabled, or set to expire at the end of the browser session, the values will not be stored, and the default values will be loaded into the 'Print Options' section each time you load the Parts List.

The Parts List Window

The browser window is initially divided into four frames: Menu, Parts List, Illustration and Control Panel.

The Menu Frame

The Menu Frame is located on the left side of the interface, and is the main navigation system through the Parts List.
Moving the mouse over a Section heading will turn that heading red, with an underline, indicating that it is a link.
  1. Click on a heading, and the menu will expand, revealing one or more sub-headings items. As an example, click on "Engine". At this point, three things will happen:
    1. The section 'Engine' will turn red as an indication that this is the current heading being viewed,
    2. the menu will expand, revealing the sub-headings for the Engine section, and
    3. the Parts List Frame will be filled with the Table of Contents for the Engine section.
  2. Click on the first sub-heading, in this case 'Engine Unit', and again, three things will happen:
    1. The sub-heading 'Engine Unit' will turn red, again indicating that this is the current sub-heading being viewed,
    2. the parts data for the 'Engine Unit' section will be loaded into the Parts List Frame, and
    3. the illustration for the 'Engine Unit' section will be loaded into the Illustration Frame.
  3. When a heading is open, there will be a '(-)' symbol beside the heading; clicking on this symbol will collapse the menu, and you will be back to the initial main menu.
  4. Clicking on another sub-heading will repeat the above steps for that particular section. Clicking on a different heading will collapse the current menu and reveal the sub-headings beneath the new heading.
  5. Both Parts Lists, the Mechanical Service Parts List (AKD 3523) and the Body Service Parts List (AKD 3524) are accessible from the same menu system. At the bottom of the main menu of the Mechanical Parts List (loaded when you first start the Parts List) is a Section heading called 'Body Details'; clicking on this Section heading will load the main menu system for the Body Parts List. Similarly, at the bottom of the main menu of the Body Parts List is a Section heading called 'Mechanical Details'; clicking on this Section heading will load the main menu system for the Mechanical Parts List.

The Parts List Frame

The Parts List Frame is located in the upper-right half of the main window.
When a Section heading is clicked, the Table of Contents for that section will be loaded into the Parts List Frame. When a sub-heading is clicked, the listing of part names and numbers for that sub-heading will be loaded.
In the Help and Explanatory sections of the Parts List, the Parts List Frame will be loaded with a variety of pages, depending on the section chosen. On some parts listing pages, there are clickable links which may be followed to other parts listing pages; the Menu and Illustration Frames will update to match the current parts listing.

The Illustration Frame

The Illustration Frame is located in the lower-right half of the main window.
When an Illustration is loaded, clicking on the Illustration image will have the following results:
  • Left Mouse Click: Clicking on the Illustration image with the left mouse button will zoom in on the image.
  • SHIFT Key Plus Left Mouse Click: While holding down the SHIFT key, clicking on the Illustration image with the left mouse button will zoom out from the image.
  • In both cases above, the point on which you clicked should never leave the Illustration Frame, re-centring itself as much as possible.
  • CTRL Key Plus Left Mouse Click: While holding down the CTRL key, clicking on the Illustration image with the left mouse button will centre the image on the point you just clicked (as much as possible), without zooming in or out. Good for navigating around a zoomed image.
    Note: On Apple Macs, use the Command Key (also called the Apple Key) instead of the CTRL Key.
Once the Illustration image is too large to fit in the Illustration Frame, scroll bars will appear in order that you may navigate around the image.
In the Help and Explanatory sections of the Parts List, the Illustration Frame will be loaded with a variety of pages, depending on the section chosen.

The Control Frame

The Control Frame is located at the bottom-right of the main window, and adds some functionality to the interface.
  • MENU | PARTS | ILLUS: Clicking on these words controls the hiding and showing of the Menu, Parts List and Illustration Frames. When the text colour of these words is black, the Frames are in their default state. When one or more of the words is red, that corresponding frame has changed from its default state.
    • MENU: Clicking on this word will hide the Menu Frame to give more screen real estate to the Parts List and Illustration Frames. The word 'MENU' will turn red; clicking on the word 'MENU' again will restore the Menu Frame to its default state (showing).
    • PARTS: Clicking on this word will maximize the Parts List Frame (and hide the Illustration Frame). The word 'PARTS' will turn red; clicking on the word 'PARTS' again will restore the Parts List and Illustration Frames to their default states (a 50-50 split).
    • ILLUS: Clicking on this word will maximize the Illustration Frame (and hide the Parts List Frame). The word 'ILLUS' will turn red; clicking on the word 'ILLUS' again will restore the Parts List and Illustration Frames to their default states (a 50-50 split).
    • Note: If either the words 'PARTS' or 'ILLUS' are red, clicking the word that is black will immediately switch the state of both frames.
      • For example: The word 'PARTS' is red, which means the Parts List Frame is showing (and the Illustration Frame is hidden). Clicking on the word 'ILLUS' (which is black) will immediately show the Illustration Frame and hide the Parts List Frame; at the same time, the word 'PARTS' will turn black, and the word 'ILLUS' will turn red.
  • RESET ILLUSTRATION: Clicking on these words will resize the current Illustration image in the Illustration Frame to its initial size. Good when you have zoomed in several times and want to view the entire image again. If the initial/reset size of the image is too large or too small, it can be changed in the Parts List Configuration' section.
  • SEARCH: Clicking on this word will replace the menu system in the Menu Frame with the Search Frame. The word 'SEARCH' will be replaced by the words 'EXIT SEARCH' (in red); clicking on these words will return you to the main menu system. More information on searching the Parts List can be found under the Help section 'Searching'.
  • PRINT: Clicking on this word will resize the Menu Frame, revealing the Print Frame below . The word 'PRINT' will be replaced by the words 'HIDE PRINT' (in red); clicking on these words will hide the Print Frame, and expand the Menu Frame to its former size. More information on printing the Parts List can be found under the Help section 'Printing'.
  • CONFIG: Clicking on this word will bring you to the configuration section. See Configuring the Parts List for more information.
  • HELP: Clicking on this word will load the Help Table of Contents into the Parts List Frame, and the Help file itself into the Illustration Frame.

Two additional frames can be loaded, the Search and Print Frames. These are accessible by clicking on the words 'Search' and 'Print' in the Control Frame, respectively.

The Search Frame

When the word 'SEARCH' is clicked in the Control Frame, the menu system is replaced by the Search Frame. The Search Frame provides the functionality to search the database by Part Number and Keyword. Details on the use of the Search Frame can be found in the Help Section entitled 'Searching'.

The Print Frame

When the word 'PRINT' is clicked in the Control Frame, part of the Menu Frame is replaced by the Print Frame. The Print Frame provides the functionality to print each page of the Parts List. Details on the use of the Print Frame can be found in the Help Section entitled 'Printing'.

Searching

This Parts List has the ability to search the database by Part Number and Keyword.

Overview

  • To open the Search Frame, simply click on the word 'SEARCH' in the Control Frame at the bottom of the Parts List Window.
  • At any time, you may return to the main menu by clicking on 'Return to Main Menu' in the Search Frame, or by clicking on 'EXIT SEARCH' in the Control Frame.
  • Initially, a quick list of tips is shown which highlights the important features of the search. Clicking on 'Search Tips' at any time will show this list again. Clicking on 'Full Help' will load the Help Table of Contents and the full Help file into the Parts List and Illustration Frames, respectively.
  • At the top of the Search Frame, enter the Part Number(s) or Keyword(s) into the textbox under the label 'Enter Search Keywords'.
  • Click the button labelled 'Search' to begin the search.
  • The search results will be shown in the Search Frame; each result will have the name of the Section page where the Keywords were found, as well as how many matches were found on that page (in blue).
  • The name of the Section page is a link to that page. This link may be followed without leaving the Search Frame.
  • If there are more than 10 results, only the first 10 will be shown initially. Use the 'Next' and 'Previous' buttons to navigate forward and backward through the list of search results.
  • If you enter a Part Number or Keyword that either cannot be found or that appears on more than a specified percentage of pages, a dialog box will notify you of this situation. If the search contains other Part Numbers or Keywords that can be found, the search will continue with these Keywords.

General

  • A Keyword can be regular words (such as distributor) or part numbers (such as AEC133703).
  • The contents of the search may contain any letter, number, and the following characters: _ - . ' , $ %.
  • The search is case insensitive.
    Examples:
    1. To search for the word 'Carburetter', you could enter 'carburetter', 'carBureTTer', 'CARbuRetter', (minus the quotes) or any other crazy variation into the search textbox.
  • Currently, the search cannot use wildcards such as '*' or '?' to search for partial matches. As well, only whole words will be searched.
    Examples:
    1. Entering the Keyword 'carb', (minus the quotes) into the search textbox will not find any of these words: carburetter, carburetters, carbs, etc, but will only find the word carb.
    2. Entering the Keyword 'carb*', (minus the quotes) into the search textbox will not find any of these words: carburetter, carburetters, carbs, etc, but will only find the word carb*.
  • Common words (i.e. words appearing on the vast majority of the pages) are excluded from the search index. This prevents common words from returning too many search results.

Searching for Part Numbers

To search for a part number, enter the entire part number into the search box, omitting any spaces within the part number. If you are searching for more than one part number in a single search, separate the part numbers with a single space. (See Searching with Multiple Keywords for more on multiple Keyword searches)

Examples:
  1. To search for part number AEC 1337 03, you would enter 'AEC133703' (minus the quotes) into the search textbox.
  2. To search for part numbers AEC 3106 or AEC 3168, you would enter 'AEC3168 AEC3106' (minus the quotes) into the search textbox.

Searching for Keywords

To search for a Keyword, enter the Keyword into the search box; to search for multiple Keywords, simply enter each Keyword into the search textbox, separated by a single space. (See Searching with Multiple Keywords for more on multiple Keyword searches)

Examples:
  1. To search for 'Piston', you would enter 'piston' (minus the quotes) into the search textbox.
  2. To search for 'Overdrive' or 'Piston', you would enter 'overdrive piston' (minus the quotes) into the search textbox.

Searching with Multiple Keywords

This search engine supports searches with multiple Keywords using the modifiers '+' and '-'. The modifier '+' means that the Keyword after it must appear on the page, while the modifier '-' means that the Keyword after it must not appear on the page.

Examples:
  1. To find all the pages that contain either the Keyword 'Distributor' or the Keyword 'Cover', you would simply enter 'distributor cover' (minus the quotes) into the search textbox. This is similar to the Boolean search: distributor OR cover.
  2. To find all the pages that contain both the words 'Distributor' and 'Cover', you would simply enter '+distributor +cover' (minus the quotes) into the search textbox. This is similar to the Boolean search: distributor AND cover.
  3. To find all the pages that contain the word 'Distributor', but not the word 'Cover', you would simply enter 'distributor -cover' (minus the quotes) into the search textbox. This is similar to the Boolean search: distributor NOT cover.

British Terminology

Since this was a British publication, the spelling and terminology are distinctly British. To make the Keyword search function useful, you must not only use Keywords that contain British spelling, you must use British terminology when referring to specific parts of the car.

Examples:
  1. Searching using the Keyword 'carburetter' will find the device that mixes fuel and air; however, the Keyword 'carburetor' will not be found.
  2. A search for 'hood' will return (mostly) pages for the mechanism that covers the cockpit, not the pieces of steel and aluminium that cover the engine compartment; for the latter, you would need to search for 'bonnet'.

Printing

This Parts List has the ability to print the pages presented in it, a pair of pages at a time: a page of the Parts List along with its associated Illustration.

Overview

  • To open the Print Frame, simply click on the word 'PRINT' in the Control Frame at the bottom of the Parts List Window.
  • There are two sections in the Print Frame: 'What to Print', and 'Print Options'.
  • The length of the page printed and the size of the illustration page printed is controlled in the 'Print Options' section.
  • Clicking on the 'Print Preview' button will open one or two new browser windows, depending on what is selected in the 'What To Print' section.
  • Each page is printed from those new browser windows, using the browser's printing controls.
  • Clicking on the 'Save Print Configuration' will save the current options entered in the 'Print Options' section.

What To Print Section

This section contains two checkboxes, initially checked, labelled 'Parts List (Upper) Frame' and 'Illustration (Lower) Frame'. When checked, the corresponding frame will be selected for printing. The 'Parts List (Upper) Frame' checkbox refers to the Parts List Frame which, most of the time, displays the pages containing the part descriptions and part numbers. The 'Illustration (Lower) Frame' checkbox refers to the Illustration Frame which, most of the time, displays the pages containing the illustrations.

Print Options Section

This section contains four textboxes:
Line spacing:
This textbox sets the line spacing, which is the distance between lines, expressed as a percentage. The smaller the line spacing value, the closer together each line will be printed. Reducing this value will allow more to be printed on a page. However, setting this value too low will cause side effects, such as overlapping lines or text that is cut off.
Default: 120%
Image height:
This textbox sets the height of an image on an illustration page, expressed in pixels. The smaller this value is, the smaller the image will be, allowing an illustration to fit on a single page. It is not necessary to adjust the width of the image, as the program will automatically preserve the image proportions.
Note: This option controls the printed size of the images only, and is different from the 'Sizing of images on load' value in the Configuration. See Parts List Configuration for more details.
Default: 850 pixels
Print Windows:
This option sets the initial size of the two new browser windows. There are two textboxes, one which sets the width, one the height, of the new windows, expressed in pixels. The smaller each of these values, the smaller the new browser windows will be.
Default: Width: 600 pixels; Height: 400 pixels

Print Preview

  • Clicking on the 'Print Preview' button will open one or two new browser windows, each containing the page currently loaded in the Parts List Frame and/or the Illustration Frame.
  • From each of these windows, select the Print Preview function of your browser to see if each page will print the way you want.
  • If the information in either browser window runs longer than a page, reduce the values of the 'Line spacing' option (for pages containing mostly text) or the 'Image Height' option (for illustration pages) until the print preview shows that the pages fit on a single piece of paper.
  • Once you are satisfied with the way the page looks in Print Preview, you can use your browser controls to send the pages to the printer.

Save Print Configuration

  • Clicking on the 'Save Print Configuration' will save the values entered in the textboxes in 'Print Options'.
  • These values are stored in a cookie in your computer's browser. If you have cookies disabled, or set to expire at the end of the browser session, the values will not be stored, and the default values will be loaded into the 'Print Options' section each time you load the Parts List.

Tips & Tricks

Tip: Printing

Because there is a lot of information on each of the pages, try these suggestions to print a single page without page breaks:
  • Set your margins as wide and as tall as your printer will allow
  • Turn off the printing of headers and footers that your browser prints on pages; these just take up valuable space. (Note: In Mozilla and IE, headers and footers can be changed or removed in File/Page Setup.)
  • Turn on background images to print row shadings; without the row shadings, reading across the page can become very difficult
  • Print in as high quality as possible, both because the print is small and the diagrams can be quite complex

Tip: Bookmark the Parts List in Your Browser

Bookmarking the main Parts List file in your browser will save you time when opening the Parts List. You can use a bookmark with either the CD in the CD-ROM drive, or on the hard drive if you have placed the CD-ROM contents on your hard drive.

Tip: Place CD-ROM Contents on Hard Drive

Placing the contents of the entire CD-ROM onto your hard disk has several advantages:
  • Because the images used in this Parts List are quite large, there can be a noticeable delay in displaying the images in your browser; factors that affect this delay are the speed of the CD-ROM drive, the speed of the computer's CPU and the current load (both CPU and memory) on the computer. Because CD-ROM drives transfer data quite slowly compared to hard disk drives, placing the Parts List on your hard drive could noticeably improve response.
  • Sometimes you just need to have the Parts List handy for quick reference. While the CD-ROM is a great format, sometimes getting out the CD (if you can find it), putting it in the drive and opening up the Parts List may not be worth your while to look up just one part number. By putting the Parts List on your hard drive and bookmarking it in your browser, the Parts List is always available.
  • If you have your home computers networked, then you could access the Parts List from the computer beside your Healey (what, you don't have a computer in your garage/shop/workspace?).
General Procedure To Place Parts List on Hard Disk
  1. Make sure you have at least 120MB free hard disk space
  2. Create a new directory or folder on your hard drive where you would like to put the Parts List
  3. Transfer all the files on the CD-ROM (including index.html and all the directories and sub-directories) to the new directory on your hard drive
  4. When the transfer is complete, in your browser, bookmark the file 'index.html' in the new directory on your hard drive, for easy access to the Parts List

Cookies, Privacy and Security

What is a Cookie?

A cookie is a piece of information that gets entered into the memory of your browser, and is set by the visited website (in this case the Parts List). If the lifetime of this information is set to be longer than the time you spend at that site, then this piece of information is saved to a file on your hard drive for future reference by that website.

What Cookies Does this Parts List Use?

This Parts List uses cookies to remember configuration settings. Two cookies will be stored on your computer: one (called 'akd_partslist') that contains the settings from the Configuration Section, and one (called 'akd_partslist_print') that contains the settings from the Print Frame. If you decide to disable cookies in your browser, this Parts List will still function normally. The only degradation in features would be that your configuration settings are not remembered between uses of the Parts List; a bit of a pain, but liveable. Also, there is an expiration date set on these cookies, which means that if you don't use the Parts List for a year (365 days), the settings will revert back to the defaults.

Privacy and Security

This Parts List does not collect any personal information about you, your computer or anything else. In fact, it doesn't collect any information at all (except for the configuration information as outlined above). It does not contain any spyware, adware or malware.
The Parts List uses Javascript functions to enhance and automate the Parts List. The functions do not connect to the Internet for any purpose. The Parts List has one page (in Help>Updates) that connects to the Internet to enable you to download updates for the Parts List; this page does not collect nor does it send any personal information about you, your computer or anything else, except what is normally sent by a browser when connecting to an Internet site.
