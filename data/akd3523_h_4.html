How To Update The Parts List CD-ROM

Note: In order to view the Update information in the Illustration Frame and to download the Update file, you must be connected to the Internet.

First, review the information in the Illustration Frame, indicating what updates, if any, are available and the changes from your version of the Parts List.

There are two ways to update the Parts List CD-ROM. Each has its advantages and disadvantages.
  1. Purchase Most Recent Version of CD
    Purchasing the most recent version of the Parts List is the simplest method of obtaining the most recent updates on CD-ROM. To purchase an updated Parts List, simply click on the link to LBCdigital.com in the Illustration Frame.

    Benefits of purchasing the CD include:
    • Contents of the updated CD include the entire Parts List, not just the update.
    • No need to mess around with files on your computer's hard drive; perfect for those who are less than confident when dealing with computers.
    • You can carry the updated CD with you to tech sessions without fear of having out-of-date information.

  2. Download the Update File
    While downloading the update file is free, it requires more work than simply purchasing a new CD. This method requires you to have copied the contents of the entire CD to your hard drive, download the update file and, optionally, burn another CD-ROM.

    Benefits of downloading the Update include:
    • After applying the update, you have immediate access to the updated Parts List; no waiting for the CD to arrive in the mail.
    • Save the cost of a new CD and use the money you saved to buy another series of Parts List at LBCdigital, or to buy something else for your Healey, or possibly to buy a nice gift for your significant other who lets you work on your Healey!

Applying the Update

Purchased Updated CD, But Have Not Transferred Files of Original CD onto Your Hard Drive
If you have not transferred the Parts List to the hard drive on your computer, then simply insert the CD into your CD-ROM drive and:
  • If you previously bookmarked the main Parts List page, simply open that bookmark, or
  • If you have not previously bookmarked the main Parts List page, open the file 'index.html' in the main CD-ROM directory.
Purchased Updated CD, Have Transferred Files of Original CD onto Your Hard Drive
If you have previously transferred the files of your original CD onto your hard disk, then simply erase the contents of the directory where you placed the files and replace them with the contents of the updated CD. For a summary of how to transfer the CD contents to your hard drive, see 'Tip: Place CD-ROM Contents on Hard Drive' in the 'Tips & Tricks' section of the Help file.

Downloaded Update, Have Transferred Files of Original CD onto Your Hard Drive
In order to use this option, you will need to transfer the files from your original CD onto your hard drive, if you haven't done so already. For a summary of how to do this, see 'Tip: Place CD-ROM Contents on Hard Drive' in the 'Tips & Tricks' section of the Help file.
  1. Transfer the files from your original CD onto your hard drive, if not done already.
  2. Download the most recent Update file (in one of the available formats), and save it in the same directory where you placed the contents of the CD.
    • Hint: This will be in the same directory as the file named 'index.html'.
  3. Uncompress the Update file, allowing it to overwrite files.
  4. Open your browser and:
    • If you previously bookmarked the main Parts List page, simply open that bookmark, or
    • If you have not previously bookmarked the main Parts List page, open the file 'index.html' in the directory where you placed the contents of the CD.
Downloaded Update, Burn a New CD
In order to use this option, you will need to transfer the files from your original CD onto your hard drive, if you haven't done so already. For a summary of how to do this, see 'Tip: Place CD-ROM Contents on Hard Drive' in the 'Tips & Tricks' section of the Help file. You can also choose to burn the files onto a CD-R or CD-RW.

The general procedure (different CD-burning programs will differ slightly) is:
  1. Transfer the files from your original CD onto your hard drive, if not done already.
  2. Download the most recent Update file (in one of the available formats), and save it in the same directory where you placed the contents of the CD.
    • Hint: This will be in the same directory as the file named 'index.html'.
  3. Uncompress the Update file, allowing it to overwrite files.
  4. Delete or move the downloaded Update file, otherwise it will be included in the .iso image created in the next step.
  5. In your CD-burning software, create an .iso image of the files and directories created in Steps 1 and 3.
    • Hint: As an option, you can create a multisession .iso image; this will allow you to burn future updates onto this CD.
  6. Burn the CD with the multisession .iso file created in Step 5.
Downloaded Update, Re-burn Original CD
All CDs purchased from LBCdigital are CD-R discs that have been burned in "multisession" mode. This means that the CD can be re-burned with an .iso file made from the Update file.

WARNING! LBCdigital will not be responsible for any damage you do to your Parts List CD-ROM disc with this method of update. We provide this option for those that are technically-minded and wish to have the updates all on one CD. Also, even if you do all the steps properly, the burning process can still lead to a corrupted or unreadable disc (commonly referred to as a "coaster"). If you have never re-burned a CD before (or even if you have) and really wish to try, we suggest first practising with a CD-RW disc; this way, if you make a mistake, you haven't made a coaster.

The general procedure (different CD-burning programs will differ slightly) is:
  1. Backup, backup, backup your CD onto your hard drive, in case something goes wrong with the burning process.
  2. Did we mention that you should backup your CD onto your hard drive, in case something goes wrong with the burning process?
  3. Download the most recent Update file (in one of the available formats), and save it to an empty directory.
  4. Uncompress the Update file.
  5. Delete or move the downloaded Update file, otherwise it will be included in the .iso image created in the next step.
  6. In your CD-burning software, create an .iso image of the uncompressed files and directories created in Step 4.
    • Note: Make sure the directories in the .iso image correlate exactly with the directories on the CD-ROM, otherwise, the updates will not be applied properly.
    • Note: Make sure that you create a multisession .iso image; this way, you can update the CD if a new Update file is released.
  7. Take a deep breath, cross your fingers and exhale slowly.
  8. Burn the CD with the multisession .iso file created in Step 6.
